<acceptance_criteria>

## AC-1: Isolated persistence
```gherkin
Given the Day 6 database is configured on 127.0.0.1:5433
When migrations and the explicit seed command run
Then 12 synthetic institutions, 288 reports and their derived indicators are persisted without touching port 5432
```

## AC-2: Honest overview
```gherkin
Given the user has a valid local demo session and the database is reachable
When the overview loads
Then every displayed KPI is calculated from persisted records and the page marks the dataset and training thresholds as synthetic
```

## AC-3: Directory search and detail
```gherkin
Given the user is signed in
When they search by institution identifier or name and open a result
Then the server returns a bounded, matching page and the detail view shows period/source-linked reports and exceptions
```

## AC-4: Explicit failure
```gherkin
Given the database or demo credentials are unavailable
When the user requests data or signs in
Then the application shows an actionable error and never substitutes success-shaped empty data
```
